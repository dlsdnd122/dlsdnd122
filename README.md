## 🚀 Projects

### 📚 EduDesk — 영어학원 강사용 AI 단어시험·업무 자동화 플랫폼
> 강사가 직접 하던 단어시험 출제와 시험지 제작을 자동화하는 서비스

- **멀티테넌시**: `school_id` 기반 row-level 테넌시로 학원별 데이터 분리
- **LLM 파싱 파이프라인**: PDF 파싱 실패 시 멀티모달 fallback, `is_verified` 필드로 검수 흐름 설계
- **문서 생성**: 템플릿 기반 PDF 렌더링 파이프라인
- **협업**: GitHub Organization + GitHub Flow로 3인 팀 운영
